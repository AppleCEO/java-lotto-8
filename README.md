# java-lotto-precourse

1. 로또 구입 금액을 입력 받는다. "구입금액을 입력해 주세요."을 먼저 출력하여 안내한다. 수량을 입력받고 "몇 개를 구매했습니다."를 출력한다.
2. 당첨 번호를 입력 받는다. 번호는 쉼표(,)를 기준으로 구분한다. "당첨 번호를 입력해 주세요." 를 먼저 출력하여 안내한다.
3. 보너스 번호를 입력 받는다. "보너스 번호를 입력해 주세요." 를 먼저 출력하여 안내한다. 발행한 로또 수량 및 번호를 출력한다. (로또 번호는 오름차순으로 정렬하여 보여준다.) "보너스 번호를 입력해 주세요."를 먼저 출력하여 안내한다.
4. 당첨 번호와 발행한 로또 번호를 비교하여 당첨을 확인한다.
5. 당첨 내역을 출력한다. 수익률을 표시한다. (문서를 참고)
6. 예외 처리, 예외 상황 시 에러 문구 출력
